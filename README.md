# Zelda64Recompiled PAL Translation
it's exactly what it says :) 

REQUIRES: EZ Text Replacer API for Zelda64Recompiled

Included Languages:

    English (PAL)
    German
    French
    Spanish

Paste the nrm file in your mods folder and you're good to go!
Select your preferred language via the Configuration Tab.
